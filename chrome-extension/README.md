# B&Y CRM Click-to-Call Chrome Extension

This extension intercepts phone number clicks on Google Search, Google Business Profiles, and any website, bypassing browser protocol prompts, and routes calls directly into your B&Y CRM.

## How to Install (Takes 10 Seconds):

1. Open **Google Chrome** and go to: `chrome://extensions/`
2. Turn ON **"Developer mode"** (toggle in the top-right corner of Chrome).
3. Click **"Load unpacked"** (top-left button).
4. Select this folder: `f:\dineshworks\CRM\chrome-extension`

Done! Now whenever you click any phone number on Google Search, Chrome will instantly open your CRM tab and auto-dial the call via CloudConnect SIP!
